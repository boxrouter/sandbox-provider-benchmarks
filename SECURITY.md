# Security policy

Report suspected vulnerabilities through this repository's GitHub private vulnerability
reporting when the `Security` tab offers **Report a vulnerability**. If it is unavailable,
email [security@boxrouter.ai](mailto:security@boxrouter.ai). Do not post vulnerability
details, access tokens, or release credentials in public issues or discussions.

Include the affected version or commit, a minimal reproduction, and the impact. Remove
credentials and private workload data from reports and examples.
